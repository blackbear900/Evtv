# EV TV

A Home Assistant add-on for watching IPTV in your EV, running [NodeCast TV](https://github.com/technomancer702/nodecast-tv), a web IPTV
player, and gives it a free private `https://` address with Tailscale Funnel, so it works in a Tesla's browser.

**Install:** Home Assistant → Settings → Add-ons → Add-on Store → ⋮ → Repositories → paste
`https://github.com/blackbear900/Evtv` → Add. Then install **EV TV** and follow its Documentation tab.

This add-on is only a player; it doesn't come with any channels.
